# Sendgo OpenAPI Specification

Sendgo API의 OpenAPI 3.0 스펙입니다.

- 알림톡 (Alimtalk): `POST /api/{version}/notices/send`
- 친구톡 (Friendtalk): `POST /api/{version}/friends/send`
- SMS/LMS/MMS: `POST /api/{version}/messages/send`
- 토큰 발급: `POST /api/{version}/token`

## 사용법

[Swagger Editor](https://editor.swagger.io)에 `openapi.yaml` 파일을 붙여넣어 API를 시각적으로 탐색하세요.
